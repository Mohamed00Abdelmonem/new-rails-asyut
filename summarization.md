
----------------------------- Active Record vs Repository Pattern --------------------
Active Record combines data and behavior in the same model.

Repository Pattern separates database access logic from business logic, making the code easier to test and maintain.

Rails uses Active Record by default because it is simple and productive.




 ----------  Rails Migrations  -----------------

Migrations are used to manage database schema changes through Ruby code.

They provide version control for the database and allow teams to apply changes consistently across environments.
